# royal-limo-develop - Limo Booking (Develop Snapshot)

Development snapshot of the **Royal Limo** platform: Next.js frontend + Express/MongoDB API.

## Overview
Active development layout for the limousine booking product, organized as separate frontend and backend apps.

## Key Features
- Next.js customer/admin UI
- Express REST API
- Auth (JWT), bookings, and content modules
- MongoDB data store
- Cloudinary integration for media

## Tech Stack
- **Frontend:** Next.js, React, TypeScript, Radix UI
- **Backend:** Node.js, Express, MongoDB, JWT
- **Folders:** `frontend/`, `backend/`

## Getting Started
```bash
# API
cd backend && npm install && npm run dev

# Web
cd frontend && npm install && npm run dev
```

Configure environment variables locally (MongoDB URI, JWT secret, Cloudinary keys). Do not commit `.env` files.
